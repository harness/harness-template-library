# Harness Template Library
This repository houses a collection of Terraform templates to provide examples and solutions to manage a Harness Platform

## Summary

This repository has been created by the Harness Implementation Engineering team to provide examples and templates which can be used to manage and operate a Harness Account.

## AI-Assisted Repository Management

This repository includes agentic support infrastructure for AI-assisted development and maintenance:

- **CLAUDE.md** - Project-level instructions for AI assistants
- **AGENTS.md** - Agent-specific task routing and workflow definitions
- **.ai/repository_tasks/** - Automated workflows for CHANGELOG updates, README generation, version determination, and commit message generation

These tools enable consistent, automated management of repository documentation and versioning.
